# CLAUDE.md

Guidance for Claude Code when working in this repository. `CONTRIBUTING.md` covers how to build, test,
publish and release the Velixo CLI, and how to write its Help Center pages; read it before changing
any of those.

## Branches, commits and pull requests

Before creating a branch, committing or opening a pull request, see
`.claude/rules/jira-ticket-naming.md`: it decides how each one names its Jira ticket (`RD-<number>`).
