Velixo CLI

One binary, velixo, that runs the tools of the Velixo MCP server from the command line, for AI coding agents, scripts and people.

Install on macOS or Linux

Homebrew

brew tap velixosolutions/velixo-cli https://github.com/VelixoSolutions/velixo-cli
brew install velixo

Install script

curl -fsSL https://cli.velixo.com/install.sh | sh

Install on Windows

WinGet

winget install Velixo.CLI

Install script (PowerShell)

irm https://cli.velixo.com/install.ps1 | iex

npm (macOS, Linux, Windows)

npm install -g @velixo/cli

Then

velixo login
velixo connections list
velixo guide

An AI agent should read agent-ready.md first.

Every channel installs the same signed binary from the latest GitHub release. Update with brew upgrade velixo, winget upgrade Velixo.CLI, npm install -g @velixo/cli@latest, or by running the install script again; velixo version --check prints the command for your install. The install scripts verify the checksum, and take a version to pin one: sh -s -- 1.0.0.

Samples

Two sample apps use the CLI as their ERP back end, to show that an app in any language can read from and write to an ERP through it. Claude Code built both with the CLI signed in on demo companies. Each sample's PROMPT.md holds the prompt that built it, so you can read how it was made or build it again.

Inventory checker · Node.js, Acumatica

A full-screen kiosk for a store floor. Scan an item's barcode and it shows the item live from Acumatica: its image, the quantity on hand and available in each warehouse, the stock by location, and when the next purchase order is due. Staff can reserve units with one tap, which runs an inventory transfer.

Expense receipts by text message · Python, Acumatica and Sage Intacct

An employee texts a photo of a receipt, by SMS or in a Telegram bot. The app finds the employee by the phone number, straightens and reads the receipt, creates the expense with the photo attached, and texts back a link to it. It asks a question only when it must.
