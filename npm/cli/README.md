# @velixo/cli

The Velixo CLI, `velixo`, brings Velixo to the command line, so AI coding agents, scripts and people at a terminal can query an ERP, run ERP commands, move files and run imports from a shell.

```sh
npm install -g @velixo/cli
velixo login
velixo guide
```

The package installs the signed native binary for your platform (Linux x64, arm64 and x64 with musl, macOS Intel and Apple silicon, Windows x64 and arm64) through an optional dependency, and `velixo` runs it. Node.js is only used to start it. Update with `npm install -g @velixo/cli@latest`.

Documentation: https://github.com/VelixoSolutions/velixo-cli#readme
